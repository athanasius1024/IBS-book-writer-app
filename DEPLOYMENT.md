# Deployment

## 1. Database

```bash
./setup_database.sh
```

Prompts for the PostgreSQL host, port, database name (default `db_ibs_bookwriter`) and user (default `rock`), creates the database if needed, applies `sql/schema.sql` (idempotent, schema `scm_bookwriter`) and stores the connection settings in `.env`.

Unattended: export `DB_HOST DB_PORT DB_NAME DB_USER DB_PASSWORD` first (empty `DB_PASSWORD` uses `~/.pgpass` or peer auth).

**Upgrading an existing database:** pull the new code, then re-run `./setup_database.sh` (or just `psql -d db_ibs_bookwriter -f sql/schema.sql`) and restart the app. `sql/schema.sql` is idempotent and adds any new columns in place without touching your data (for example the content-block type, data and image columns added with the dashboard and block-type update).

Manual alternative:

```bash
createdb db_ibs_bookwriter
psql -d db_ibs_bookwriter -f sql/schema.sql
```

## 2. Configuration

All configuration is by environment variable or `.env` (see `.env.template`):

| Variable | Purpose |
| --- | --- |
| `SECRET_KEY` | Required. Signs session cookies. Generated by `start.sh` if blank. |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | PostgreSQL connection. |
| `DATABASE_URL` | Full SQLAlchemy URL; overrides the `DB_*` values. |
| `BOOKWRITER_SCHEMA` | Schema holding the tables (default `scm_bookwriter`). |
| `ALLOW_REGISTRATION` | `0` closes sign-up once the first account exists. |
| `SESSION_COOKIE_SECURE` | `1` when served over HTTPS. |
| `UPLOAD_DIR` | Where cover images are stored (default `./uploads`; back this up). |

Keep `.env` out of version control (it is git-ignored) and readable only by the app user (`chmod 600 .env`).

## 3. Run

Development / single user:

```bash
./start.sh
```

Production: use a WSGI server behind a TLS-terminating reverse proxy (nginx, Caddy, ...):

```bash
.venv/bin/pip install gunicorn
cd app && ../.venv/bin/gunicorn --workers 3 --bind 127.0.0.1:8000 "ibsbook:create_app()"
```

Set `SESSION_COOKIE_SECURE=1`, and set `ALLOW_REGISTRATION=0` after your accounts are created if the app is reachable by people you don't trust.

## 4. Backups

Back up both the database (`pg_dump db_ibs_bookwriter`) and the `uploads/` directory.

## 5. Tests

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests
```

The tests use in-memory SQLite and need no database server.
